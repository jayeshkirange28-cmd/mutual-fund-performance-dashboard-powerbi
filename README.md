📊 Mutual Fund Analytics Dashboard – Power BI

📌 Project Overview

The Mutual Fund Analytics Dashboard is an interactive Power BI project designed to analyze mutual fund performance, AUM (Assets Under Management), risk levels, returns, and AMC performance. This dashboard helps users make data-driven investment decisions by providing clear and visual insights.

🎯 Objective

The main objectives of this project are:

* Analyze mutual fund performance
* Compare AUM across different fund categories
* Identify high-return and low-risk funds
* Track AMC performance
* Provide interactive visual insights for decision making

🛠️ Tools & Technologies Used

* Power BI – Data visualization and dashboard creation
* Excel – Data source and preprocessing
* Power Query – Data cleaning and transformation
* DAX – Calculated measures and KPIs

📂 Dataset Information

The dataset includes:

* Fund Name
* AMC Name
* Category
* AUM (Assets Under Management)
* Returns (%)
* Risk Level
* Fund Type

📊 Dashboard Features

* KPI Cards showing Total AUM, Average Returns, Total Funds
* Bar Chart for AUM comparison
* Pie Chart for Category distribution
* Column Chart for AMC performance
* Interactive Slicers for filtering
* Tooltip showing detailed fund information

## 📈 Key Insights

* Identified top performing mutual funds based on returns
* Compared AUM across multiple AMCs
* Analyzed risk distribution among funds
* Helped visualize investment trends clearly
